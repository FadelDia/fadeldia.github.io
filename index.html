Getting Started

If you think the coding section of FTC may seem daunting, you aren't alone.
Luckily, FTC has a detailed documentation website all over the coding section. It is encouraged you follow the official guide and use this one as a secondary resource or overview.

First, decide what major programming platform you will use:

Block Coding - Easiest setup and simplest coding. Simply type "192.168.43.1:8080" into your browser once connecting to the robot for the program and manage website.

Onbot Java - Located in the program and manage website, this is a bridge between the robustness of Android Studio with less complexity.

Android Studio - Intended for advanced users, this allows you to sync a project via git, save previous versions or "commits," among other advanced features.

AprilTag Guide

AprilTags are visual markers with unique IDs - similar to a QR code. A robot’s vision software can use a detected tag, along with camera and tag-size information, to estimate its position and orientation.

This guide is still being developed. For official instructions, check the resources provided by FIRST.
